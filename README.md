# Pathfinding Algorithm Visualizer

A **React-based** interactive visualizer for **pathfinding algorithms**, including **BFS, DFS, Dijkstra’s, and A\***. This tool allows users to create obstacles, set start and end points, and observe how different algorithms find the shortest path.

## 🚀 Features  

### ✅ Algorithms Implemented  
- **BFS (Breadth-First Search)** – Guarantees the shortest path in an unweighted grid.  
- **DFS (Depth-First Search)** – Explores paths deeply before backtracking.  
- **Dijkstra’s Algorithm** – Finds the shortest path using a priority queue.  
- **A\* (A-Star Algorithm)** – Uses heuristics for optimized pathfinding.  

### ✅ Interactive Grid  
- Click to place **walls**, **start**, and **end** nodes.  
- Visualize algorithm execution step by step.  
- Clear and reset the grid easily.  

### ✅ Optimized for Performance  
- Efficient grid updates.  
- Fast algorithm execution.  

## 📌 Installation & Usage  

### 1. Clone the Repository  
```bash
git clone https://github.com/saicharan0107/pathfinding-visualizer.git
cd pathfinding-visualizer
```
### 2. Install Dependencies
```bash
npm install
```
### 3. Run the Application
```bash
npm start
```
This will start the app on http://localhost:3000/.
